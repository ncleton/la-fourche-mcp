# Contribution

Les correctifs doivent être fondés sur un contrat réellement observé sur le site officiel, dans une session autorisée par l’utilisateur. Les fixtures ne doivent contenir que des structures expurgées, jamais de données de compte ou de commande.

Avant une proposition :

```bash
npm ci
npm run verify
```

`AGENTS.md` reste la source de vérité commune à Codex et Claude Code.
