# Politique de sécurité

Signalez les vulnérabilités en privé avec les GitHub Security Advisories du dépôt. Ne joignez jamais de cookie, jeton, mot de passe, code 2FA, capture de compte, adresse ou contenu de commande.

Le serveur MCP doit rester en `stdio`. Camoufox doit écouter sur l’interface locale et être protégé par `CAMOFOX_AUTH_MODE=required` et une clé aléatoire forte. Chaque compte doit utiliser un `CAMOFOX_USER_ID` distinct. Le fichier `.env` et les profils Camoufox ne doivent jamais être versionnés.

Le projet est non officiel et n’est ni affilié ni approuvé par La Fourche.
